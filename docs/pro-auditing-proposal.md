# Proposed Pro auditing and compliance scope

**Tentative product proposal, not a settled packaging decision.** The owner's suggestion that auditing and compliance might be Pro features is recorded for later product design; it does not authorize removal of core safeguards or new license gates.

Potential Pro additions:

- Enhanced audit search and investigation workflows.
- Extended retention and tamper-evident archives.
- SIEM exports and managed delivery integrations.
- Compliance evidence collection, reporting and review workflows.

Core retains security-event recording, authentication, authorization and scoped permissions, credential revocation, ordinary operational diagnostics, and existing audit/history verification. This proposal removes no events, records, tests, historical verifiers or existing capabilities. Safe self-hosting does not require Fstack Cloud or a Pro license callback.

Packaging, retention policies, commercial terms and implementation remain deferred. This proposal does not delay authentication delivery to implement Pro functionality and does not promise that these candidate features already exist.
